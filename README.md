# Roberto Pignataro site customizations

Version-controlled CSS and JavaScript for the Squarespace 7.0 Avenue site at [robertopignataro.com](https://www.robertopignataro.com/).

- `rlp-site.css` contains the visual system and responsive treatments.
- `rlp-site.js` contains the section dividers, Biography index, and article enhancements.

These files are delivered to Squarespace through jsDelivr. Squarespace retains all page content, images, navigation, SEO, and publishing.
